# Module 1 — Quantitative Finance Fundamentals & Python

8 sessions covering the foundations: financial markets, data acquisition with Python/APIs,
return/risk metrics, and applied linear regression & time series basics.

Topics announced for this module (from the course syllabus, mapped to sessions as classes happen):

- Introduction to algorithmic trading, financial markets, and asset classes
- Financial data acquisition, cleaning, and preparation using Python and APIs
- Return analysis, distributions, risk/performance metrics (Sharpe, Sortino, VaR, Drawdown)
- Applied linear regression (CAPM, alpha, beta) and time series fundamentals (ADF, KPSS, AR, MA, ARMA)
