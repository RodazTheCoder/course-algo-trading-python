# Module 2 — Quantitative Modeling & Machine Learning

8 sessions covering market microstructure, stochastic processes, supervised ML for
financial prediction, and robust validation methods.

Topics announced for this module (from the course syllabus, mapped to sessions as classes happen):

- Market structure, liquidity, transaction costs, and microstructure
- Stochastic process modeling and volatility analysis (GBM, OU, GARCH)
- Supervised Machine Learning for financial prediction (decision trees, Random Forest)
- Financial feature engineering and robust validation (Walk-Forward, Purged Cross-Validation)
